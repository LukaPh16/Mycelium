# Mycelium UI plan

Goal: a cozy, cute, easy-to-understand app. Original pixel art with a warm, chunky look (wood and paper panels,
dialogue boxes, day and night palettes). Readability first: pixel font only for titles and buttons.

## Screen map

```
Splash (pixel mushroom)
  └─ Terrarium (home)                    organisms of watched apps, start/pause protection banner
     Drawer (☰ top left):
       Terrarium
       My Apps                           choose apps to watch, then pick an organism for each new one
       Activity                          live list of lookups; tap one for details
       Insights                          tabs: Garden (per app, parasites, block) | Charts (summary, timeline, top lists)
       Ask the Gardener                  chat; Ask AI preview sheet; key sheet
       Setup Check                       checklist with fix buttons
       Settings                          theme Auto/Day/Night, AI key, Advanced switch
         └─ Advanced (only when switched on)   SQL, raw call, export/wipe DB, simulation, diagnostics
       Help                              glossary and how-tos
       About & Privacy                   main message, what leaves the phone, credits, version
Top bar: ☰  title  [status chip: Protected / Paused / Safe Mode]   tap chip -> protection sheet
```
Back: system back pops screens; on home with the drawer open it closes the drawer. Predictive back enabled.

## Main-surface words (Phase 2)
DNS lookup = "contact", domain = "website or service", tracker = "Snoop" (pest sprite), block = "Shoo away",
VPN = "Protection", Sanctuary = "Safe Mode (offline)", anomaly = "Odd behavior". Technical words only in "i" sheets
and Details expanders. Copy stays honest: Mycelium sees contacts of chosen apps only, never contents, and never stops
all tracking (see the "What Mycelium can't see" page).

## Glossary (plain words, used in InfoButtons and Help)

| Word | Meaning |
|---|---|
| Garden / Terrarium | Your watched apps, each shown as a little organism that grows with its activity. |
| Organism | The creature for one app. It grows when the app reaches out to the internet. |
| Watched app | An app you picked. Only these apps go through Mycelium; others are untouched. |
| Lookup | An app asking "where does this website live?" (a DNS lookup). Mycelium sees these, never the content. |
| Tracker / Parasite | A company that collects data about you, like ad and analytics networks. |
| Blocked | You told Mycelium to stop an app from reaching that tracker. |
| Protected | Mycelium is running and watching your chosen apps. |
| Paused | Mycelium is off. Apps work normally but nothing is recorded. |
| Safe Mode | No internet right now. Mycelium answers apps on the phone and sends nothing; it sorts what it caught when you are back online. |
| Stage | How grown an organism is (1 to 3). |
| Growth | Points an organism earned from its app's activity; trackers count double. |
| Packet type | What kind of traffic it was (lookup, tracker, web, ...). Each type has a color. |
| Tripwire | A trap address: when a blocked app tries to connect anyway, it hits the tripwire. |
| Something odd | An anomaly: unusual behaviour, like many new websites at once or activity at night. |
| Simulation | A demo with made-up data, shown with a red banner. |

Spacing: 4, 8, 12, 16, 24 dp. Screen padding 16 dp. Panel padding 12 dp. Touch targets at least 48 dp.

Type:
| Style | Font | Size |
|---|---|---|
| Title (screen) | Pixelify Sans (OFL) | 22 sp |
| Section header | Pixelify Sans | 17 sp |
| Button | Pixelify Sans | 15 sp |
| Body | system sans | 15 sp |
| Small / labels | system sans | 13 sp |
| Numbers | system sans, tabular | 15 sp |

Components (app/src/main/java/app/mycelium/app/ui/): PixelPanel (wood or paper), PixelButton (primary, secondary,
danger; pressed state moves down 1 art px), InfoButton ("i" in a circle -> InfoSheet), PixelDialog (dialogue box with
a name tab), EmptyState (sprite + text + action), StatusChip, SectionHeader (title + optional InfoButton), PixelToast.
